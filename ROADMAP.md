## Ближайшие задачи

### 📋 Улучшить онбординг-чат (сбор контекста)
Сейчас бот принимает расплывчатые ответы ("да, всё ок") и отмечает поля как заполненные.

**Нужно:**
- Бот не должен считать поле заполненным пока нет конкретики
- Цены: должны быть реальные цифры, не "недорого"
- Товары: конкретный список, не "техника"
- Бот должен переспрашивать и уточнять пока не получит детальный ответ
- Поле отмечается заполненным только при наличии реальной информации

### 📋 Оптимизация голосового агента (WebSocket)
Сейчас: HTTP polling → 5-7 секунд на ответ
Цель: WebSocket → 300-400 мс

**Что нужно:**
- Переписать voice relay с HTTP на WebSocket-стриминг
- Стримить аудио-чанки по мере генерации (ElevenLabs streaming)
- Убрать промежуточное сохранение файлов

### 📋 Instagram OAuth для клиентов
После прохождения App Review — дать клиентам возможность подключить свой Instagram-аккаунт через кнопку "Connect Instagram" вместо хардкода токена в .env.

**Что нужно:**
- OAuth flow с Instagram
- Сохранение токена per-tenant в БД
- UI в настройках для подключения/отключения аккаунта

## Следующая очередь

### 📋 Интеграция с базами клиентов
Клиент хочет чтобы агент знал об остатках товара, расписании и т.д.

**Варианты:**
- Импорт CSV / Google Sheets → загрузка в контекст агента
- Tool use (function calling) — агент вызывает функцию проверки остатков в реальном времени
- Приоритет: сначала CSV/Google Sheets как статический импорт, потом tool use

### 📋 Система оплаты (эквайринг)
Подписочная модель для клиентов.

**Что нужно:**
- Выбрать платёжный провайдер (Stripe для международных, или местный для KG/RU рынка)
- Планы подписки (по числу сообщений / каналов / пользователей)
- Биллинг-страница в UI
- Ограничение функций по тарифу
